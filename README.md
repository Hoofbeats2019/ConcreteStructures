# Concrete Structures — Study Notes

My study notes for **Concrete Structures** by R. F. Warner et al.

## Layout

| Folder | What goes in it |
|---|---|
| `chapters/` | One file per chapter: summary, key ideas, questions |
| `examples/` | Worked examples and practice problems |
| `formulas/` | Key formulas and design clauses, collected in one place |
| `glossary.md` | Terms and definitions |

## How I use this repo

1. Read a chapter, then write its notes in `chapters/chNN.md` from `chapters/_template.md`.
2. Work through its examples in `examples/chNN.md`.
3. Add any new formula to `formulas/` and any new term to `glossary.md`.
4. Update the progress table above.
